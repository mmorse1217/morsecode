# Morse Code

This site uses Hugo and the vendored [Shibui theme](https://github.com/ntk148v/shibui).

Run `hugo server` to preview locally, or `hugo` to build the site into `public/`. Alternatively, use `make serve` or `make build` to run Hugo in Docker. Deploy the contents of `public/` to the web host. Edit `content/_index.md` to update the landing page.
